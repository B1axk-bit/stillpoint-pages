# 静观 · Stillpoint

行情转得再快，先看清再动。

静观是 B1ack 的投资研究框架，这个仓库是它的观点看板：把市场噪音收成一句结论、一个现在能做的动作、一条什么情况下改主意的线，再配上止跌清单、主题立场、宏观状态、中国视角和回看账本。

在线地址：https://b1axk-bit.github.io/stillpoint-pages/

> 研究框架的观点展示，不是投资建议，不对应任何买卖点位。

## 怎么更新

页面是一个静态的 `index.html`。所有会变的内容都在里面的 `<script type="application/json" id="page-data">` 这一块 JSON 里，图表由页面脚本按数据画出来。复盘后只改这块 JSON，提交到 `main`，GitHub Pages 会自动重新发布。

## 数据来源

Mac 定时快照（行情、ARGUS 指标、吸引子 19 项宏观状态指数）、当天公开报道，以及静观 skill（v0.5.1）和沧海一土狗视角 skill（v0.3）里的框架和读数。页面上每个数字都标了来源和时点。
