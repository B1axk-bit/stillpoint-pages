# 机制层细节：发散用的工具

> SKILL.md 3.1 的展开。工具跑完之后，一定要用 SKILL.md 3.2 选主线收口；拿不准时读 `main-line.md`。

## 描述系统（吸引子第一步）

先问一个问题：**涨的或跌的到底是谁？** 指数之间、板块之间、同一条产业链的上下游之间的分化，往往比指数本身信息量更大。然后列出系统里的主体、钱怎么流、货怎么流。

## 钱货四格（模型 4），把"钱"拆成量和价

- **钱的量**：银行准备金、TGA、吸引子的美元流动性指数
- **钱的价**：2 年期收益率、实际利率、资金利率指数、加息概率
- **货**：物价指数、油价、柴油

怎么组合：
- 钱多货紧 → 资源品和上游占优
- 钱紧货多 → 现金流和红利资产占优
- **钱多但贵**（量在增加、价在上涨）→ 系统层面不缺钱，但最依赖借钱的节点会被精准卡住

## 反馈环与反身性（模型 6 + 《金融炼金术》）

- 找出正反馈环和负反馈环。资源端涨价通常是负反馈（涨价让下游少买）；科技端涨价常是正反馈（涨价后能拿资产抵押，借到更多钱）。
- **反身性检查**：资产价格有没有通过抵押、融资、股权发行反过来改变基本面？如果有，这就是一个反身性的环。它在两个方向上都会自我强化。
- **繁荣—萧条序列**：判断当前处在哪一段，并给出证据。萌芽 → 自我强化、加速 → 经受考验 → 信念增强 → 现实和预期背离 → 黄昏期 → 拐点 → 加速下跌。
- **流行偏见**：市场现在普遍相信什么？哪个数据一出来就能证伪它？

## 三分法（ARGUS）加启发式 9

每次下跌都要分清楚是哪一种，各配一张证据表：

| 类型 | 典型证据 |
|---|---|
| 流动性压力 | 资金市场紧张（SOFR−IORB 持续为正）、VIX 飙升、3–4 个标准差的偏离、被迫抛售 |
| 融资压力 | 个别借款人的债券收益率飙升、IPO 推迟、融资条款变差 |
| 经营恶化 | 订单、收入、毛利、现金流跨层下滑 |

只有真正的流动性冲击，才是"乱中取利"的入场信号。融资压力和经营恶化对应的是等待或回避。

## 生态位（启发式 14）

区分生态组织者（或瓶颈）和消耗型节点，用三道筛子：
1. **生态位**：它是在制定标准、分发流量，还是卡住了别人绕不开的瓶颈？
2. **能量留存**：毛利率是否高且稳定，扣掉资本开支后自由现金流是否为正？
3. **钱从哪来**：扩张主要靠自己的经营现金流，还是靠高息债？

## 防止一招鲜

每次分析至少用两个心智模型，而且要和上一次复盘换一个维度。七个模型是工具箱，不是固定的两颗药。

多用模型是为了不漏看，代价是结论容易散。所以这些工具跑完之后，一定要用 SKILL.md 3.2 选主线收口。换维度指的是发散时用的工具，不是主线；主线过了检验就留着。

## 资产专题打法

问到具体资产时，先用上面的通用骨架，再用下面的专题拆法补上这类资产特有的驱动。专题里的"怎么读"是推理规则，不是历史定律。

**美元和汇率**：拆成四个驱动，分开看证据。
1. **利差**（钱的价）：美联储比别国更鹰，美元就强。看 ARGUS 的 `treasury-2y`，外国收益率和央行动向用公开报道补。
2. **贸易条件**（货）：油价冲击时，能源净出口的美国受益，进口国（欧元区、日本、韩国）的货币偏弱。看布伦特。
3. **避险**：全球风险偏好下降，资金回流美元。看吸引子的全球风险偏好指数和 VIX。
4. **"卖美国"**：美债收益率上升、美元却下跌，说明市场在担心美国的财政和信用。看期限溢价（`term-premium-10y`）、国债拍卖认购和黄金。这也是一种美元拐点，但对风险资产是最坏的一种。

怎么读：四个驱动里有几个同时转向，才算拐点。风险资产下跌、美元却没涨，只是早期信号，不是确认。传导方向是：美元越强，吸引子的中国外部金融条件（`att_00003413`）越紧，新兴市场、A 股和港股越受压。案例见 `analysis/2026-10-15-美元指数拐点与skill优化.md`。

**黄金**：三条腿，判断这次是哪条在推。
1. **实际利率**（ARGUS 的 `real-yield`）：实际利率下降是持有黄金的传统理由。
2. **美元**：美元走弱，以美元计价的黄金走强。
3. **避险和信用对冲**：地缘冲突、"卖美国"、央行购金（用公开报道核实）。

怎么读：实际利率在升、黄金也在涨，说明推动它的是第 2 或第 3 条腿。这时不能拿"实际利率高"当看空黄金的理由，要去查是谁在买。数据看快照里的 COMEX 黄金和伦敦金。

**A 股**：四个看点。
1. **政策**：逆周期调节和资本市场政策，用公开报道，以官方发布为准。
2. **成交额**：快照里的两市成交额。只跟自己以前的快照比放量还是缩量，不用记忆里的"正常水平"。
3. **板块分化**：快照里的行业板块排行。看领涨和领跌是不是同一条主线的两头，例如 10/15 设备股北方华创 +3.95%、光模块新易盛 −7.49%：跟美国 AI 资本开支绑得越紧的越弱，靠国产替代的越强。
4. **内外宏观**：外部看吸引子中国外部金融条件、美元和离岸人民币；内部看中国流动性、信用环境、总需求和物价。

北向资金不再实时披露，不用它当路标。

**存储周期**：存储是 AI 链里周期性最强的一环。
- **三个量**：合约价（DRAM、NAND）、库存天数、厂商资本开支。合约价用 TrendForce 这类行业机构的报价，通过公开报道获取，并注明发布日期。
- **反馈环**：涨价是"货紧"，但存储的供给弹性大，涨价会引来扩产，形成负反馈。所以拐点看资本开支指引和库存，不看当期利润。利润最好的时候，往往离扩产最近。
- **竞争变量**：中国厂商扩产会削弱涨价的持续性，10/15 的复盘里把它列为基本面的问号。
- **数据缺口**：快照的观察清单里还没有存储个股，暂时用 KOSPI 当代理，个股价格靠公开报道补。

## 沧海一土狗四问（A 股、人民币、楼市）

问 A 股风格、人民币、中国楼市和债市时，在上面的工具之外加这四问。细节和阈值从 `canghai-tugou` 的SKILL.md按当前引用读取，先核实际文件，不能沿用旧发行包路径。

1. **两因素**：无风险利率（CNH 强看一年存单利率，弱看两年美债）和楼市（北京二手挂牌量、一线房价环比）有没有变？没变，就去外部和资金结构里找原因。
2. **风往哪吹**：CNH 升值、中美缓和 → 内需板块占优（降波牛）；贬值、紧张 → 外需和科技占优（升波牛）。科技上涨要配合升波，降波上涨不持续。
3. **资金结构**：相对收益资金抱团时市场效率低、趋势强，换主线等右侧信号（小市值或红利收盘下穿 20 日均线）；保险等杠杆资金减仓时，看 TL 和银行股是否还出挑。
4. **PPI 往哪走**：PPI 弱利成长和小微盘，PPI 强利价值，也撑人民币（土狗的模型 11）。

为什么加这一层：吸引子和 ARGUS 的数据偏美国，对 A 股风格和人民币的拆法偏少，土狗的框架正好补这一块。它的阈值同样是研究规则，不是历史定律。快照还缺沪深300 IV、双创 ETF_IV、外汇掉期点和一年期存单利率，缺就写缺。
